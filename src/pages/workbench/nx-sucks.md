## Nx sucks. Here is why

[Nx](https://nx.dev/getting-started/intro) is a multitool for JavaScript ecosystem, that's responsible for managing a project's technical development part.
On top of that the company offers (paid) cloud tools that integrate with tools running locally, providing fully-fledged *improved* developer experience.

It is best known for managing monorepos.

<small class="disclaimer">
  Monorepo is single version control repository containing multiple projects usually of the same programming language.
  Monorepos are very practical, but might be complex to manage.
</small>
